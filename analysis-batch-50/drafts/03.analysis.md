# 康熙帝玄燁｜他能替帝國劃定邊界，卻無法替皇權劃出繼承的界線

康熙帝玄燁，是中國歷史上最擅長處理複雜危機的皇帝之一。

他十幾歲便擊倒權傾朝野的鰲拜，二十歲面對三藩叛亂，三十歲將清朝統治延伸至臺灣，此後又在黑龍江流域與俄國角力，在蒙古草原與噶爾丹展開長期戰略較量。

但這位幾乎一生都在解決政治危機的皇帝，晚年卻親手兩次廢黜自己培養數十年的皇太子，讓皇室陷入愈來愈深的權力競逐。

這個矛盾，比「康乾盛世的開創者」更值得研究。

康熙最卓越的能力，不是每場戰爭都能打贏，而是他懂得不同敵人需要不同的勝利條件：三藩必須消滅其獨立軍政權力，臺灣必須建立持續行政管轄，俄國可以透過條約建立邊界，蒙古各部則需要軍事壓力與政治聯盟並行。

他能夠在戰爭、談判、封賞與制度之間靈活轉換。

然而，一旦問題回到皇帝自己與兒子的關係，他那套高度有效的危機治理方法，反而逐漸失去作用。

他能讓疆域內外的強者學會服從皇權，卻無法讓未來的皇帝在自己活著時，既擁有繼位資格，又不威脅自己的權威。

這正是康熙六十一年統治最深刻的成就與裂縫。

## 1.【歷史局勢與定位】：他不是接收盛世的人，而是替清朝完成第二次建國的人

康熙於1654年出生，1661年順治帝去世後即位，當時只有八歲。索尼、蘇克薩哈、遏必隆、鰲拜四位輔政大臣奉遺詔處理政務。

表面上，他繼承的是已經入主北京十餘年的清朝。

實際上，這個王朝尚未完成真正的整合。

首先，中央權力仍受到滿洲勳貴集團牽制。鰲拜憑藉軍功與輔政地位干預重大決策，連其他輔臣都難以抗衡。

其次，清朝對南方的統治高度依靠明末降將。吳三桂控制雲貴，尚氏鎮守廣東，耿氏掌握福建，各自具有龐大的軍事與地方資源。

再次，臺灣仍由鄭氏政權統治，東北面臨俄國勢力進入黑龍江流域，漠北蒙古各部則處在清廷、準噶爾及其他地方政治勢力的競爭之中。

清廷名義上已是天下共主，卻未必能直接命令每一支軍隊、每一處邊疆與每一個地方權力中心。

這是康熙真正繼承的帝國。

1669年，康熙逮捕鰲拜。《清史稿》記載，他事先挑選善於角力的年輕侍衛，以遊戲方式訓練，待鰲拜入見時將其拘捕。

大臣議請族誅，康熙念其舊功免其死罪，但對其部分黨羽施以嚴厲懲處。

這個事件展現出少年皇帝兩種截然不同的能力：敢於突然出手，也懂得區分首領與整個政治集團的處置方式。

參見[《清史稿》卷六，康熙八年](https://zh.wikisource.org/wiki/%E6%B8%85%E5%8F%B2%E7%A8%BF/%E5%8D%B76)。

但鰲拜事件只是開始。

康熙真正的政治生命，是在1673年至1681年的三藩戰爭中得到鍛造。

他決定撤藩，吳三桂反叛，耿精忠與尚之信先後捲入局勢。戰爭波及大片南方地區，清廷一度陷入嚴重危機。

勝利之後，1683年清軍攻克澎湖，鄭克塽率鄭氏政權歸降；1684年清廷在臺灣設置府縣。

1689年，《尼布楚條約》確立清俄在東北部分地區的邊界安排。1691年，喀爾喀蒙古各部在多倫諾爾會盟後與清廷形成更緊密的政治關係。1696年，清軍又在昭莫多重創噶爾丹。

這些成果說明，康熙不只是維持順治朝的既有局面，而是大幅提高中央對疆域、軍隊與地方政權的實際控制能力。

不過，必須區分康熙時期取得的成果與後來整個清朝的擴張。準噶爾汗國並未在其統治期間徹底滅亡，十八世紀中葉清朝對西域的征服，也不能提前算成康熙個人的功績。

康熙的歷史定位，是將一個尚未穩定的征服王朝，改造成具備長期統治能力的多民族帝國；他完成的是決定性的整合，而不是所有疆域問題的最終解答。

## 2.【深度功過剖析】：他真正的本事，是知道哪一場仗必須打，哪一場仗必須停

### （一）平三藩：他最大的軍事成就，也始於一次危險的政治賭博

1673年，尚可喜請求告老，朝廷隨即面臨三藩去留的問題。

吳三桂隨後上疏請撤，實際上帶有試探朝廷的意味。康熙批准撤藩，將長期存在的地方軍政矛盾推向決戰。

這個決定極有魄力，卻不是沒有代價的完美算計。

吳三桂在當年起兵，清廷面對南方多地響應、部分官軍失利、地方控制動搖的局面。青年皇帝必須承受自己決策所造成的戰略壓力。

北京大學歷史學者徐凱對吳三桂討清檄文的研究，亦對1673年撤藩與反叛經過作了具體考證。

參見[〈吳三桂討清《檄文》原文本考〉](https://ir.pku.edu.cn/handle/20.500.11897/464369)及[故宮博物院〈三藩〉](https://www.dpm.org.cn/lemmas/241557.html)。

【反常識論點】：康熙平三藩的偉大，不在於他一開始便看準所有風險，而在於他發現風險遠超預期後，仍能逐步修正作戰方式，沒有讓局部失敗轉化為整個朝廷的崩潰。

他調度滿洲宗室將領、漢軍及地方綠營力量，重用圖海、王進寶、趙良棟等將領，並對願意重新歸附的地方勢力採取區別處置。

這種安排未必處處順利，卻逐漸削弱了叛軍之間的協調能力。

1681年，清軍攻入昆明，三藩戰爭結束。

康熙贏得的不只是一次內戰，而是中央不再需要長期容忍南方世襲軍政集團的局面。

但戰爭造成的生命與財產損失，亦不能因勝利而消失。

其政治功績在於建立更穩定的中央控制；其代價，則是主動撤藩所觸發的長期戰亂。

### （二）臺灣與鄭氏：真正的勝利發生在海戰結束之後

1683年，康熙命施琅率水師進攻臺灣鄭氏政權。施琅在澎湖取得關鍵勝利，鄭克塽、劉國軒等人隨後歸降。

這場勝利必須將皇帝的戰略決策與施琅的海軍指揮分開評價。

康熙提供政治授權、將帥任命與戰後處置方向；具體渡海作戰、艦隊組織及澎湖戰役，主要是施琅與相關將領的功績。

但1684年設立臺灣府縣、隸屬福建，才使軍事征服進一步轉化為持續行政管轄。

參見[《清史稿》卷七，康熙二十二、二十三年](https://zh.wikisource.org/wiki/%E6%B8%85%E5%8F%B2%E7%A8%BF/%E5%8D%B77)。

更值得注意的是，康熙並未將所有鄭氏舊將一概視作必須消滅的敵人。鄭克塽獲得封爵，劉國軒也受到任用。

他懂得一個極其重要的道理：若投降意味著完全失去生存空間，戰爭就可能被迫延長；若舊敵仍能在新秩序中找到位置，軍事勝利便更容易轉化為政治穩定。

當然，臺灣並不是等待朝廷填補的空白土地。鄭氏統治、漢人移民及原住民族社會各有既存秩序，清朝行政制度向臺灣延伸的過程也存在新的權力衝突。

康熙完成的是清廷對臺灣政治控制的重要轉折，而非島內所有社會整合問題的結束。

### （三）雅克薩與噶爾丹：他懂得用外交保住戰略主動權

康熙在東北與漠北的處理方式，最能說明他不是只懂發動戰爭的君主。

1685、1686年前後，清軍在雅克薩與俄國勢力發生軍事衝突。1689年，雙方簽訂《尼布楚條約》，就額爾古納河、格爾必齊河等邊界安排達成協議，俄方撤出雅克薩。

康熙並沒有要求戰爭無限延長，直到俄國徹底喪失在東北亞的所有影響。

他接受談判，將部分戰場成果轉化為條約秩序。

參見[《尼布楚條約》漢文界碑](https://zh.wikisource.org/wiki/%E5%B0%BC%E5%B8%83%E6%A5%9A%E6%A2%9D%E7%B4%84_%28%E6%BC%A2%E6%96%87%E7%95%8C%E7%A2%91%29)。

原因不只是外交上的仁慈。

當準噶爾勢力正在蒙古草原形成嚴重威脅，與俄國維持長期戰爭，就可能使清廷同時面臨兩個難以控制的邊疆戰場。

康熙的戰略選擇，是在東北建立可操作的邊界，將更多力量投入北方蒙古問題。

1690年，噶爾丹與清軍在烏蘭布通交戰。康熙原擬親臨前線，卻因患病未能抵達主要交戰地點。

1691年，多倫諾爾會盟鞏固清廷與喀爾喀蒙古的關係。

1696年，康熙親自統率中路軍出塞，費揚古率西路軍，在昭莫多取得關鍵戰果。1697年，噶爾丹在進一步軍事壓力及部眾瓦解之下死亡。

昭莫多之勝，不能說成康熙本人在戰場上親率騎兵擊潰敵軍；但三路進軍、糧草組織、戰略包圍與政治招撫，確實展現其帝王層級的軍事統籌能力。

《康熙朝實錄》卷一六九記錄了分路出兵、軍糧與驛站安排，也留下康熙對1690年未能親臨前線的反思。

參見[《康熙朝實錄》卷一六九](https://zh.wikisource.org/wiki/%E5%BA%B7%E7%86%99%E6%9C%9D%E5%AF%A6%E9%8C%84/%E5%8D%B7%E4%B9%8B169)。

這場戰爭最重要的歷史意義，是清廷以軍事、蒙古部族聯盟及地方政治安排，加強了對漠北的控制。

### （四）「永不加賦」：最成功的仁政，也是一場精明的財政與人口管理改革

康熙經常被描述為一位善於減稅、重視民生的仁君。

但1712年「滋生人丁，永不加賦」政策的真正巧妙之處，不只是減輕新增人口的負擔。

當時各省人丁登記存在隱匿問題。如果增加登記人口便意味著增加丁銀，民眾與地方官便可能有動機少報。

康熙五十一年二月的諭旨要求，以原有在冊人丁數作為徵收丁銀的固定基礎，日後新增人丁另造冊登記，不再因此增徵丁銀。

其實際邏輯是：不再把新增人丁直接視為新的徵稅來源，才有可能讓地方更願意呈報真實人口。

參見[《康熙朝實錄》卷二四八](https://zh.wikisource.org/wiki/%E5%BA%B7%E7%86%99%E6%9C%9D%E5%AF%A6%E9%8C%84/%E5%8D%B7%E4%B9%8B248)及[中國人民大學清史研究所相關研究](https://iqh.ruc.edu.cn/kxyj/kydt/c5529c15e38f4d01a83a3ec4b6c5739b.htm)。

這項改革對後來雍正朝的攤丁入畝具有重要影響，但兩者不能混為一談。

康熙沒有在1712年直接廢除所有丁稅，也不能把十八世紀人口增加完全歸功於這一道政策。

同樣地，他六次南巡既有視察河工、了解地方的功能，也具有安撫江南士紳、鞏固統治合法性的政治意義。

參見[故宮博物院〈康熙南巡圖〉藏品介紹](https://www.dpm.org.cn/collection/paint/228301.html)。

康熙的仁政，並不是慈善家的單純施予，而是讓民生改善、財政秩序與皇權合法性產生共同收益的治理設計。

### （五）晚年政風與財政：他能容忍人的缺點，卻低估了缺點變成制度慣例的危險

康熙晚年最大的行政問題，不是突然停止勤政。

《清史稿》記載，即使在晚年，他仍頻繁處理奏章、巡視河工、安排邊防軍需。

但勤政不等於制度一定有效。

隨著國家日益龐大，地方財政支出、軍事供應、官員俸給及耗羨收入之間的矛盾逐漸積累。

中國人民大學清史研究所對清代耗羨歸公制度的研究指出，康熙中後期地方虧空日益嚴重，官員低薪與地方經費不足亦是重要原因；康熙晚年已試圖清查虧空，但並未完全解決。

參見[中國人民大學清史研究所相關研究](https://iqh.ruc.edu.cn/old/qdzzsyj/gjzz/847247658ea94b07a3372af841b74dc0.htm)。

這不能簡化為「康熙寬仁，所以官員全部腐敗」。

更精確的問題在於：當地方官必須完成大量行政任務，卻缺少透明、穩定的經費安排時，皇帝即使不斷要求廉潔，仍難以根除制度性灰色收入。

另一方面，康熙對文化與政治反對力量並非一味寬容。

《康熙朝實錄》記載，1712年《南山集》案牽涉戴名世、方孝標及相關人員，廷議提出極其嚴厲的刑罰與株連處置。

這提醒我們：康熙的寬仁有明確政治邊界；凡被視為威脅王朝正統與統治安全者，仍可能面對高度強制性的國家權力。

## 3.【人性與性格側寫】：他能理解每個政治對手，卻無法容忍繼承人過早變成另一個自己

康熙的人格核心，是一種罕見的組合：高度好奇、強烈自信、精力充沛，以及對失去最高控制權的深層警覺。

他並不是只依靠臣下奏章了解世界的宮廷皇帝。

他重視騎射，經常行圍；又學習漢文經典、數學、曆法，接觸西方傳教士帶來的知識。

《康熙朝實錄》卷一八九甚至記載，他於1698年行圍時親自射殺兩隻虎，其中一隻隔澗中箭。

這反映出他對個人技藝與武備傳統的重視。

但對康熙而言，學問與騎射還有另一層政治功能。

他不願只做八旗貴族的君主，也不願只做漢人士大夫心中的儒家皇帝；他希望自己能在各種文化與權力語言中，都具有無法輕易取代的權威。

這也是他頻繁巡幸、親自接見蒙古王公、主持經筵及重視南書房文臣的原因之一。

然而，這種自信也有其反面。

康熙習慣親自決定大事，習慣透過自己的判斷化解各派矛盾。這使他在外部危機中具有極強的調度能力，卻也使權力交接成為難以處理的問題。

1675年，康熙立年幼的胤礽為皇太子。

這項決定有助於穩定皇位繼承預期，也包含他對已故皇后赫舍里氏之子的特殊感情。

但隨著胤礽成年，太子逐漸形成自己的政治地位，問題便開始出現。

1708年，康熙第一次廢黜胤礽，指責其行為不當及形成黨羽。1709年，他又恢復胤礽的太子身份。

1712年，胤礽再度被廢。

這不是一個簡單的「父親太過溺愛兒子」的故事。

更深層的矛盾是：皇太子必須足夠有權威，才能讓天下相信將來有人繼承皇位；但只要太子真的形成獨立政治力量，又可能讓仍在位的皇帝感到威脅。

康熙在戰爭中可以分派將領，在外交中可以接受妥協；唯獨在皇位問題上，他無法將最終權力切分出去。

1708年討論重新建儲時，部分大臣推舉皇八子胤禩，康熙拒絕。這顯示皇子與官僚之間的政治網絡已經深深介入繼承問題。

參見[《清史稿》卷八，康熙四十七年至五十一年](https://zh.wikisource.org/wiki/%E6%B8%85%E5%8F%B2%E7%A8%BF/%E5%8D%B78)、[故宮博物院〈允礽〉](https://www.dpm.org.cn/lemmas/244122.html)。

他的盲點，不是缺少判斷力，而是過於相信皇帝個人的判斷，終究可以代替一套穩定而可預期的繼承秩序。

這種政治心理或許與他的少年經歷有關。

他曾經在輔政大臣控制下成長，又親手打倒鰲拜，因而非常清楚權力可能如何從君主身邊流失。

這可以作為理解其高度警覺的一種心理推論，但不能將其視為史料直接記載的秘密動機。

結果卻十分鮮明：他讓清朝的外部政治秩序越來越穩固，卻讓皇室內部的未來權力安排越來越不確定。

1722年，康熙去世，皇四子胤禛繼位，是為雍正帝。

康熙留下了一個疆域廣大、政治影響力顯著提升的清朝，也留下了財政管理、吏治與皇權繼承方面亟須後繼者處理的難題。

## 4.【如果生在現代】：他會是最強的跨國危機整合者，卻未必是最好的接班制度設計師

如果康熙生活在現代，他最適合的角色，不是安坐辦公室的傳統行政主管。

他更像是一位同時處理地緣競爭、組織整合、外交談判與財政改革的跨國集團總裁，或大型國家治理體系的最高戰略決策者。

他最突出的本事，是能分辨不同問題的本質。

面對鰲拜型的內部權力壟斷者，他會先建立可靠的核心執行團隊，再突然重組決策權限。

面對三藩型的半獨立地方集團，他會承擔重整成本，逐步收回總部對關鍵資源的控制。

面對俄國型的外部競爭者，他不會永遠追求零和對抗，而會尋求能夠將衝突限制在可管理範圍內的正式協議。

面對蒙古各部那樣利益不同的合作對象，他則會結合利益安排、政治承認與必要的安全保障，建立多層次聯盟。

這種能力，是極高水準的戰略治理。

但他也會是一位令人感到壓力的領導者。

他喜歡親自掌握資訊，可能建立多條直接向最高領導者匯報的通道；他重視績效，也可能讓高階主管過度依賴他的個人裁決。

在現代組織中，這種風格容易形成創辦人依賴症。

尤其在接班問題上，他可能犯下一個致命錯誤：提早指定接班人，卻不願真正容許接班人建立獨立權威；等到對方形成團隊，又開始擔心其威脅自己的位置。

康熙最需要學習的現代制度，不是更精密的控制術，而是讓最高權力可以在不依賴領導者個人情感的情況下，完成透明、穩定的交接。

他的歷史價值並不因晚年的失誤而消失。

平三藩、納臺灣、處理清俄邊界及整合漠北蒙古，都是具有深遠影響的實體政治成果。

但他也證明了一件事：

一位能夠征服廣大疆域、調度無數軍隊的君主，未必能夠征服皇權自身所造成的恐懼。

康熙帝的S-級定位，因此具有清楚的雙面性：對外部危機有極高戰略兌現力，對內部制度的長期自我修復與權力交接，卻留下相當沉重的課題。
