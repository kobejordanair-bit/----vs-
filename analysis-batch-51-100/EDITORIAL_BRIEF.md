# 第二批編輯要求

作者為 Claude Code (Anthropic)，使用真實 claude.ai/code/session_… provenance；不冒用 ChatGPT。既有原 PROMPT、四章賞析、第五章五維、七欄內核与深度評鑑均保留。

1. 先建立一句人物專屬主論點，再用至少兩個具體抉擇／場景與關係支撐。每個人的內在矛盾、語言節奏和敘事入口要有差異；換成其他人物後仍成立的段落應重寫。
2. 評價可以銳利、可以下結論，但必須有史實與可追溯的推論鏈。必要時清楚區分史實與心理判讀；不以缺證據為由發明對話、私心、診斷或確定因果。
3. 不反覆在正文寫「本文未核」「通行史實」「資料極少」等工作流程套話。查證工具受限、只讀摘要等記入 search-log、review、limits；若限制會實質改變結論，正文用一句具體說明。
4. 靈魂內核不是再寫一次政治論文：呈現人物如何說服、信任、逃避、承受挫敗，並用事件支持。七欄標籤固定，欄內節奏與畫面可變；減少反覆用「真正追求／共同結構／最根本的衝突」串接。
5. 現代映射不必人人 CEO／COO／CFO，職業比喻須貼合人物且交代邊界。不硬套病理診斷。
6. 五維五項都寫具體事例、同類參照與短板，保持原分數規則；文章長度以足以論證為準，避免用重複句拉長。
7. 必須實際上網搜尋；優先原典、官方檔案、学術资料。原典引句須經 archive-quote.mjs 全文定位。官方網址、同名人物與現代人物生卒須逐一核對；摘要不得標成已讀全文。
8. 先完整完成一人並通過 finish 與結果重建，再繼續。不得碰正式網站、私有備份、密鑰、OAuth、.env 或其他人的已發布欄位。
