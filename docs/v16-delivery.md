# v16.0 完整整合交付

## 這次的產品範圍

以既有網站翻新，保留原人物庫、分析文章、程式與存檔；新增世界書桌、人物原文與史料背景橋接、可重播的爭霸／魂穿規則，以及全功能備份。原 AI 模式保持可用，也可帶入同一份選角、引用與玩家解讀。

這個版本把「閱讀與查證 → 選角與解讀 → 行動與後果 → 存檔與回顧」串成完整流程。人物文章可以直接參與玩法，不必先全部轉成數值資料。

## 新世界如何使用原資料

- 人物依原始 ID 連接；同名人物不合併，自訂人物可直接選入。
- 原分析完整留在人物館，選段以欄位、起訖字元與原引文核對。文章變動使錨點失效時，需重新選取，不能悄悄換掉引文。
- 原五維評值作為遊戲輸入。沒有有效評值時，使用明示的中性預設；不把閱讀量、原典出現次數或 AI 印象當史實能力值。
- 每位最多八則分析錨點、整個背景最多四十則。玩家可寫完整解讀，並選擇民生、秩序、進取、協調或學習原則。
- 同一段原文的原則由玩家選擇，不由姓名或關鍵字自動推斷。實踐效果、違背成本與獎勵次數可在回合預覽查閱。
- 事件背景帶入人物身份、源文年帶、地點、勢力、來源主張。缺少事件角色連結時明示「創作設定」。即使使用歷史事件，後續分支仍是遊戲推演。
- 建立世界時凍結人物、評值、引用、原則及背景。後來修改人物庫或下一局選角不會改寫已存世界。

## 存檔與還原

### 三層資料

1. 原人物館：既有 `/api/userdata` 十欄，保留原 revision 與還原確認流程。
2. 新世界：獨立 `/api/world-workspace`、`worldworkspaces` collection；同樣使用登入驗證與 revision。最多十二局，總體 8 MiB。
3. 本機研究與朝堂：維持其原存檔格式；全功能備份會收納允許的鍵及復原版本，不掃描其他網站資料或金鑰。

### 平常使用

先保存本機，再同步雲端。頂列顯示是否同步成功。網路失敗時原進度留在本機；衝突會保留兩版，明確選「接續雲端」或「使用本機同步」。不自動猜測哪份應覆蓋。

### 換機或完整備份

在舊瀏覽器登入後，選「全功能備份 → 下載全功能備份」。新裝置可先預覽此檔，再分步處理本機玩法與原人物館雲端資料。全功能備份可能含私人文章及對话，请自行妥善保存。

還原前可下載目前完整備份。本機寫入失敗會嘗試回復全部已寫入項目；如果連回復也受配額限制，會下載含還原前／擬寫入內容的復原檔。人物館雲端需另走原確認窗，不能把本機還原成功稱為雲端也成功。

Render 沿用 `backend` 工作目錄及現有 Procfile、MongoDB、登入密碼與 Gemini 設定。v16 沒有修改原人物館 collection，也不會批次遷移原文章。第一次只讀新世界時，不會自動建立或覆蓋任何文件。

來源檔案館資料沿用既有 `b66c5a60a41e2334` 發佈，無須重新匯入原典。來源署名、擷取版本、權利與缺文標示均保留在原檔案館。

## 檢驗與界線

- 測試涵蓋規則、完整治理／外交／魂穿結局、人物原則、原文變動、重播、場景身份、AI 背景只注入一次、真實整頁啟動、UI 操作、雲端衝突、配額失敗、舊版備份與 API 路由。
- 962 筆私人快照逐筆通過 ID、原文 profile 與開局格式檢驗。這是既有 2026-09-30 快照驗證，不等於從正式雲端新抓一份完整備份。
- 沒有以模型實際生成付費內容作驗收；AI 封裝、串流與保存使用受控回應測試。現有 AI 供應商仍為 Gemini。
- 本次以 Node/jsdom 與 HTTP 驗證；先前的自動審查拒絕瀏覽器操作，因此沒有宣稱完成真實瀏覽器畫面或手機視覺驗收。
- 楚漢結構化歷史仍是選定事件切片；962 份人物檔案並不表示每篇私人分析都逐條查證。原典全文目前 29 部、4,254 個文件快照，其中 445 個標有缺文或未完整。
- 世界的經濟、地域、資源、人物關係、對手策略是清楚標示的遊戲規則。目前沒有可核實的全歷史人口、產出、疆界或精確地理模型。
- 正式網站可隨時使用。localhost 開發網址僅在本機服務執行時有效；本次交付沒有將託管改到 Cloudflare。
