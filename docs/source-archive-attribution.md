# 來源署名與版本

## 維基文庫轉錄

古籍來源為[中文維基文庫](https://zh.wikisource.org/)。每個篇章保留原網站 URL、固定修訂 `oldid`、修訂時間、取得時間、修訂歷史入口，以及原始維基文字與整理文字的 SHA-256。

署名：**中文維基文庫及各篇章修訂歷史所列貢獻者**。個別貢獻者名單可從每篇的 `historyUrl` 查閱；指定轉錄版本可從 `revisionUrl` 查閱。

古代底本與現代轉錄、註釋、校勘和編排的權利並不相同。本包按平台適用的 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 條件標記可適用的貢獻；再散布時須保留署名、版本連結、授權連結與修改说明。實際權利仍以各篇標記、底本與所在地規則為準，不將所有內容一律宣稱為公有領域。平台的[版權說明](https://zh.wikisource.org/wiki/Wikisource:版權信息)亦列在每本書的 metadata。

所做修改：保存 API 返回的原始維基文字；另以程式整理部分模板、連結與 HTML 格式為便於搜尋的純文字。未逐卷校勘，整理文字可能與網站排版或跨頁嵌入內容不同；原始文字和固定版本供核對。未知模板保留可見標記以免假裝內容已解析。書中所述史事也不是取得版本後即自動成立的現代事實。

## 維基百科書目線索

人物百科候選、書名／篇名及引用連結來自各候選頁的指定修訂；每頁保存版本、頁面 ID、取得時間及來源 URL。署名：**維基百科及各條目貢獻者**。适用的貢獻依 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)；此包抽取書目 metadata，沒有存入百科文章全文。書目可能重複、不完整或混含編輯註記，未宣稱每條外鏈均已開讀。

## 機構與研究資料

來源目錄保留機構入口、使用限制及查閱狀態。核讀紀錄由 Codex 輔助整理，只記錄支持哪個最小命題及段落定位；內容採自寫摘要，沒有整批轉存受限的現代書籍或機構全文。引用不表示來源機構為本 app 背書，也不表示獨立人類專家審查。

CBDB 的不同版本有不同條款；本包不包含其可下載資料庫或新線上 API 資料。CText 自動存取受限時沒有繞過限制。近現代名單、人物索引與傳記的證據強度不同，須一併保留核讀範圍。

## 原人物庫與程式

原人物庫是使用者既有作品／資料，公開包僅含建檔所需 metadata，不包含原長篇分析。上述平台文字授權不會自動改變原 app 程式、使用者原文或其他資產的授權。重新發布整個 app 前應按各素材自己的授權處理。
