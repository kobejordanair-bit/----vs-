# 共用資料上的五種互動

2026 年 10 月 2 日的史論館以楚漢資料包 1.1.0 和案件集 1.0.0 提供五個入口。案卷館已有六案、十八章、三十個閱讀任務與評議收束；其他入口保留自由查找、對讀與創作的空間。

## 玩家實際會做什麼

| 入口 | 反覆操作 | 原資料如何參與 | 需要保留的界線 |
| --- | --- | --- | --- |
| 案卷館 | 開案、讀材料、做核對任務、加入原分析、提出解釋及反證、收藏評議 | 六案引用共用主張；原分析可成為被支持、質疑或修正的對象 | 任務答案只核對材料讀法，不能裁定人物心理與道德；結案不等於研究已定論 |
| 時空探索 | 篩年份區間、人物、古地名、勢力，追查來源及事件關係 | 相同人物的身份與行動隨事件而變；地點、關係、路線共用來源 | 年帶相交是可能涉及；示意位置和線長不是座標或距離 |
| 人物原典 | 搜尋目前載入的所有人物，按分類及文章情況篩選，二至三筆並排對讀、選段 | 私人完整快照可讀 962 筆，原評級、五維、簡介與分析保持各自出處 | 能瀏覽不等於已完成史料連接；能力數值是原作者評定，不是歷史量測 |
| 自由調查 | 自選問題、材料、支持／質疑／脈絡／未定分類，留下結論和疑問 | 公開史料與原庫段落可同桌比較，仍保留不同知識狀態 | 材料數量不代表解釋正確；缺原文時保留引用缺口 |
| 創作工坊 | 選事件與人物，檢查參與記述、記下場景構想 | 可見有行動、被提及、參與未知或未記載的差別 | 同事件不等於同室；未記載不等於不可能；改編需要由作者明示 |

## 一次完整的案卷調查

六案分別處理鴻門的傳訊與多方行動、南鄭受任的推薦與禮遇、下邑至固陵的合作條件、井陘的未採用提案與偵察、濰水的對敵判斷，以及蕭何的行政供給與論功。

玩家先看一個可由材料處理的疑問，再沿三章閱讀。單選、多選和排序會提供每個選項的具體回饋，讓玩家看清楚哪一步把告發當成已證事實、把提案當結果、或把後來職任提前。所有案件可直接進入，不以先完成另一案作解鎖條件。

原人物分析在這個過程中有實際用途：玩家挑一段談謀略、知遇、用人、政治處境或功績的解讀，將它與某次事件的行動相比。最後留下自己的解釋、另一種解釋或反證，以及尚未解決的問題。評議可以收藏，日後用舊版繼續修訂，也可回到原材料改變立場。

本卷沒有要求原分析段落必須達到最低數量。蕭何、彭越、龍且等人在目前私人快照中沒有三類長文；玩家仍能用原簡介及史料完成案卷。韓信、漢高祖、項羽的多類分析與張良的深度分析，則提供現成的對讀內容。詳細設計見[案卷編寫規則](history-case-authoring.md)。

## 962 筆原資料的用法

「人物原典」使用目前實際載入的完整陣列，不限於楚漢包已連接的身份。搜尋涵蓋姓名、時代、稱號、簡介、詩詞及長文；帝王、將帥、謀臣條目各自保留。可同看二至三筆原文，讓同人不同身份或不同人物的作者解讀互相對照。

私人完整快照有 962 筆，不隨公開專案分發。沒有私人檔時仍可用內建人物庫與六案；使用者可在「我的人物庫與書桌」讀入完整陣列、characters 包裝，或原 App 的 customLegends／modifiedLegends 匯出。

楚漢包仍只精確連接 19 位歷史人物的 20 個原條目。其他條目可以作為原庫解讀材料閱讀和比較，但不因此獲得完整的史料年表或真實交往關係。劉邦與漢高祖保留同一歷史身份下的兩筆原庫文章，避免覆寫。

## 原文引用如何保存

原文以純文字讀取，不執行其中 HTML。段落按空行分隔；單一區塊再按換行切段。案卷及自由調查保存原 ID、姓名、分類、欄位、段號、段落及全文內容指紋，連同玩家的材料分類及筆記。原分析仍標示為作者／AI 解讀。

工作台不自動把原長文放入 localStorage 或書桌匯出檔。關閉後再次開啟，需重新讀同一人物 JSON 或由私人預覽載入快照，才能重現相關段落。若段落已改、全文其他地方已改或原庫尚未載入，會分別呈現狀態；已知舊版引用沒有指紋時也要求重新核對。指紋只協助辨識內容變更，不替作者或史實作認證。

## 保存、匯入與復原

localStorage 保存同一網址來源、同一瀏覽器的書桌進度，包括案件、材料引用、玩家文字、自由調查及創作工坊選擇。進度帶資料包及案件集版本。收藏評議保留版本；還原前保存當前草稿，容許繼續修訂。

「匯出書桌備份」下載 JSON；「匯入書桌備份」先驗證並顯示摘要，讓使用者選擇合併或接續匯入版本。同案不同版本保留於草稿管理，自由調查同題衝突保存副本。已知舊版比較 JSON 可轉入；不支援或損壞的檔案不改寫目前書桌。

保存受阻時，頁面會說明目前僅留在記憶體並提供匯出。若另一分頁已更新同一存檔，停止覆寫並保留目前頁面內容；舊存檔讀不懂時也不自動清除。管理頁可以下載保留的原檔、先備份舊檔再啟用目前工作，或接回已保存草稿。

私人文章不會自動包含在書桌備份；玩家自行寫入或貼入筆記的內容會包含。切換連接埠、使用 localhost 代替 127.0.0.1、換瀏覽器或清除網站資料，都可能使原 localStorage 不能在新位置直接取得，因此備份是跨環境帶走工作的方式。

若文字超出欄位或存檔限制而未加入書桌，介面持續標明未保存並保留草稿。使用者可下載最新未保存文字 `.txt`，另下載上次有效書桌 `.json`；後者不會混稱已包含最新輸入。一般長文欄位上限 20,000 字元，材料筆記為 10,000 字元。

## 資料與成本

```text
共用 schema + 楚漢資料包 1.1.0 + 案件集 1.0.0
                       ↓ 驗證與索引
案卷館 / 時空探索 / 人物原典 / 自由調查 / 創作工坊
                       ↑
         內建人物庫或本頁讀入的私人 JSON
                       ↓
       原文選段、材料比較、玩家署名評議
                       ↓
   本機版本存檔 / 書桌匯出匯入 / 評議封存與復原
```

工作台的查詢、核對題、原文比對與保存均不呼叫 AI 或付費模型 API。頁面請求本站靜態資料，私人 loopback 預覽可唯讀載入指定的人物快照；不向雲端寫入原人物內容。既有 App 的模型功能不由這套調查操作觸發。

## 如何比較方向

案卷館提供一次有開端與收束的短循環，時空探索提供跨事件追查，人物原典讓原有長文成為主要閱讀材料，自由調查容許玩家選擇議題並延伸追問，創作工坊則承接想寫場景的人。五者可共享引用和身份，不必為了選核心先重寫人物庫。

目前產品判斷是優先觀察玩家是否願意用史料挑戰原分析，再修訂自己的評議；這會直接檢驗既有長文的互動價值。若玩家更常自發尋人、跨事件追蹤或寫場景，便有理由調整各入口的主次。自由調查目前從既有事件及異說選題，可在筆記中提出自己的追問；新增具名自訂題目的介面尚未提供。

需要實際試玩才知道的包括：三章閱讀負擔是否合適、選項是否促進思考、玩家是否主動找反證、原分析是否帶來新問題，以及完成一案後是否想再開一案。資料量、通過任務數與結案率只能描述使用情形，不能單獨證明好玩或學到正確歷史。

首包仍為 `curated-slice`：沒有全人物生卒、完整楚漢年表、全疆域或可計算經濟模型。要拓展戰略模擬，仍需補充相應的時空及數量證據；本次六案使用的是有來源的定性關係、行動與不同解釋。
