# 第二步擴充：邊境六旬 v15.13

## 可玩的新範圍

- 六回合戰役，八位可任命人物：韓信、蕭何、魏徵、張良、陳平、孫武、商鞅、蘇秦。
- 每回合同時安排一份內政令與一份外勤任務；同一人不能兼任兩個執行職務。
- 腹地糧倉、北境關隘、河道商路三條戰線有獨立守備與補給狀態。
- 北境騎軍與河道聯盟是架空敵對勢力，具備兵力、補給、凝聚度與依局勢改變的行動。
- 偵察、護運、整訓、奇襲、交涉可改變戰線及敵方狀態；內政仍需支付真實成本、管理民間利益與到期承諾。
- 結算顯示政令、任務、敵方行動及其原因；戰役紀錄保留每回合因果。
- 遊戲流程不呼叫模型 API，因此試玩回合不消耗 AI token。

完整數值與行動順序見 [戰役規則](court-campaign-rules.md)。這是對現有試作的擴充；八位人物尚不代表 962 人物均已轉成遊戲角色。

## 人物文章與史料

人物文章透過既有人物館按姓名及分類精確讀取，保留原 ID、原文及個別章節。原人物文章與遊戲存檔各自保存；人物缺少既存深度分析時直接說明。

人物同場、台詞、數值、敵對勢力及勝負條件都是跨時代架空遊戲改編。來源連結列在人物面板與規則文件，作為改編線索；遊戲人格、能力數值與插畫是創作。

## 三版存檔

- v1：`court-grain-v1` / `dynasty_court_grain_v1`，原三選一規則。
- v2：`court-grain-v2` / `dynasty_court_grain_v2`，三回合多方議政規則。
- v3：`court-grain-v3` / `dynasty_court_grain_v3`，六回合戰役規則。

新局預設 v3，舊版保留自己的引擎、存檔與續玩入口，不自動遷移。匯入按版本完整重播、比對欄位與結果，再確認取代同版本本機進度。

本機戰役存檔透過戰役畫面的下載／匯入保存，尚未加入原 App 的雲端十欄資料或完整人物備份。完整人物備份 schema 維持 1；舊 App 讀新版本完整備份前需先更新 App。

## 美術

沿用既有朝堂場景及三位人物肖像，增加五張人物插畫。生成模式、完整 prompts 與資產位置見 `backend/static/game/court/assets-prompts-v3.md`。戰線圖為介面內繪製的示意圖。

## 驗證與交付

115 項 JavaScript 測試與 30 項後端資料測試通過。另以實際 UI 程式完成新版六回合與舊版三回合 DOM 整合驗證：草案不直接執行、雙人分工、敵方戰報、三版存檔隔離、匯入驗證、原文清理、非同步讀取及零模型呼叫。

獨立審查確認八人方法與敵方轉向有效，資源預覽和實際結算一致；補給、外交、情報反擊及集中單一戰線的完整路線呈現不同局勢。實際瀏覽器的視覺排版、鍵盤操作與下載落地仍需人工確認；DOM 測試不替代這些確認。

新程式維持在 PR #39，供試玩與審阅。本次尚未合併至 main，尚未部署 Render。
