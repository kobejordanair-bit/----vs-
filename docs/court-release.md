# 第二步：朝堂危局 v15.11

本次是「缺糧朝會」可玩樣板。從人物館上方的「朝堂危局」進入；韓信、蕭何、魏徵的卡片也有劇本入口。

## 可玩內容

- 三次朝議，分配糧儲、國庫、民心與邊防。
- 三位跨時代人物提出不同主張，留下信任與先前命令的記憶。
- 糧車、盟約及駐軍續餉在後續回合結算；選擇前顯示成本、條件及已知後果。
- 26 條合法完整路徑，五種結局。因果紀錄與結局回顧均依已執行的規則產生。
- 一張朝堂場景與三張人物插畫，在遊戲開啟時載入。
- 人物分析面板唯讀目前人物館的完整文章，缺文時清楚提示，不自動生成。

人物主張、台詞、插畫與劇本均為遊戲改編，不代表真實同場事件。一般操作不呼叫模型 API。

## 存檔範圍

本劇本以獨立鍵 `dynasty_court_grain_v1` 保存在瀏覽器，含回合、信任、待結算事件及結果頁狀態。換裝置前使用劇本畫面的下載／匯入。讀取時以完整決策紀錄重新結算並比對，錯誤或不相容的檔案不能覆蓋現況；正常匯入先顯示預覽，再由玩家確認。

本局**尚未同步至雲端**，也未加入原有十欄資料備份。原有雲端人物、文章、魂穿與逐鹿存檔結構未變。若要擴充成長局，需先加入正式遊戲存檔 schema、雲端同步及完整備份往返驗證。

v15.11 可以讀取 v15.10 的原有備份；原有備份 schema 仍為 1。新的 v15.11 備份會被較舊版本拒絕，還原前應更新 App。

## 驗證

```text
node --test tests/*.test.cjs
python -m pytest -q tests/test_userdata.py
```

共 66 個 JavaScript 與 30 個 Python 測試通過；四段主頁 inline script 語法通過。獨立審查確認人物資料及雲端十欄未被劇本修改，並修正匯入檔案非同步讀取跨開窗的競爭問題。

隔離瀏覽器已完成一局、延後事件、重整續玩、錯誤檔拒絕、有效檔預覽及另一條路線還原、人物文章閱讀、因果紀錄與 Esc；375／320 像素皆無橫向溢出。預覽服務拒絕所有雲端寫入與 AI 呼叫，操作記錄沒有這些請求。

內建預覽瀏覽器取消 Blob 下載，下載事件未取得實際檔案。已核對存檔 JSON 與讀取還原，但**尚未驗證瀏覽器下載檔案實際落地**，需在一般 Chrome 操作確認。未使用不受支援的方式繞過預覽瀏覽器限制。
