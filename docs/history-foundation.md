## 五個入口如何接通

案卷館提供鴻門、南鄭受任、下邑至固陵、井陘、濰水及蕭何供給六案。每案三章、五個單選／多選／排序任務，選項回饋能連回材料。玩家最後寫下解釋、反證或替代解釋、未解問題，收藏為可再修訂的評議。所有案件可直接開啟；任務核對材料使用方式，結案不指定人物道德或心理的唯一答案。

時空探索依人物、年帶、地點與勢力查事件，並呈現有來源的事件關係及移動示意。自由調查保留選題、材料分類與筆記。創作工坊核對人物在事件中是有行動、被提及、參與未知或未記載，供場景構想使用；示意位置不代表地理座標。

人物原典瀏覽目前載入的全部原庫記錄，可以搜尋姓名、時代、稱號與原文，按分類或文章情況篩選，並對讀二至三筆條目。讀入私人完整快照後能瀏覽 962 筆；公開專案只附內建人物庫，數量依實際載入檔顯示。

962 筆可閱讀不代表已全部建立來源化歷史身份。與楚漢包精確連接的仍是 20 個原條目；其他人物可以作為原庫解讀材料加入閱讀與比較，介面保留「尚未連入歷史包」的差別。劉邦與漢高祖連到同一歷史身份，原庫的將帥類、帝王類文章各自呈現。

## 原分析、保存與復原

玩家可選取原分析段落，放進案卷或自由調查，分類為支持、質疑、脈絡或未定。段落保留原 ID、欄位、段號及內容指紋，明示為原庫作者／AI 解讀。私人長文在頁面記憶體讀取，不自動複製到公開資料包或存檔。

工作台現在以 localStorage 在同一網址來源、同一瀏覽器自動保存進度、材料引用、筆記、評議與工作區。存檔帶資料包和案件集版本。收藏評議形成保留當時材料與文字的版本；還原舊評議前會保留目前草稿。匯入先顯示內容摘要，再提供合併或接續匯入版本，同案衝突以另存草稿保留。

匯出／匯入的是書桌 JSON；它不包含人物文章全文。自行輸入或貼入筆記的文字會包含在書桌檔中。下次要讀取私人段落，需重新提供同一人物檔或由本機預覽載入快照；內容變動會顯示段落失配或全文脈絡變更，不會無聲地替換原證據。

已知舊版比較記錄可遷移；沒有內容指紋的舊段落需要重新核對。資料包或案件集版本改變時，保留筆記與舊評議，閱讀任務需要依目前資料重提。無法辨識、損壞或有懸空引用的存檔不會自動覆寫現有工作。瀏覽器禁止保存或容量不足時，工作仍保留於頁面並提示匯出；不同分頁改動同一存檔時也會停止覆寫並提示處理。

本工作台只讀本站資料與使用者選取的人物 JSON，沒有模型呼叫或雲端寫入。原人物 App 的其他功能與資料不因讀取本工作台而改寫。

一般長文欄位上限 20,000 字元，材料筆記上限 10,000 字元。若最新文字因內容或存檔上限未能加入書桌，頁面持續顯示未保存提示並保留草稿；可另下載未保存 `.txt` 與上次有效書桌 `.json`。這時一般書桌備份不會被宣稱包含尚未寫入的最新文字。

## 重建與核對

在專案根目錄執行，使用 Node，無需新增 npm 套件：

```powershell
node scripts/build-history-schema.cjs
node scripts/build-history-case-schema.cjs
node scripts/build-chuhan-package.cjs
node scripts/validate-history.cjs
node scripts/build-chuhan-package.cjs --check
```

建置程序讀取 `data/history-research/` 的五份研究輸入；案卷細分主張及核讀紀錄在 `investigation-supplement.json`。驗證器預設同時驗證共用資料包與案件集，`--check` 比較可重建內容是否與已保存 JSON 完全一致。

需要核對私人完整人物陣列時：

```powershell
node scripts/build-chuhan-package.cjs --check --verify-library "完整人物快照的絕對路徑.json"
```

身份核對只讀原 ID、姓名、分類，檢查原快照與精確對應，不寫回私人檔。資料、引擎、建置與預覽服務的檢查方式見[啟動及發布指南](history-investigation-release.md)。一致性驗證不能證明所有史實已定論，功能檢查也不等於玩家已認定好玩。

## 開啟與下一步觀察

正常啟動既有後端後可開 `/history-lab`；也可用獨立 Node 預覽服務開啟 `/history-lab.html`。本次帶 962 筆快照的預覽為 `http://127.0.0.1:8877/history-lab.html?local=1`。它只在目前電腦提供服務，進程關閉後需重新啟動；啟動命令及無私人檔的用法見[指南](history-investigation-release.md)。

目前的產品判斷仍是優先觀察史論調查：玩家是否會因原人物分析主動找支持與反證、是否願意修正評議，以及是否想開下一案。六案提供可完成的短循環，探索、全庫閱讀及創作工坊則容許不同偏好的玩家從其他入口進來。不能只用資料量、任務完成數或結案數，宣稱互動價值已經驗證。
