# 楚漢共用資料包與玩法比較

2026 年 10 月 1 日完成第一份可重建的楚漢資料包。它把原人物庫身份、事件時間、古地名、當時勢力與來源接通，並支援三種互動樣本。原人物文章仍能直接用於閱讀與調查；本包保存其身份對應，未將私人文章全文複製進公開資料。

## 已交付內容

| 項目 | 位置與用途 |
| --- | --- |
| 共用格式 | [資料契約](history-data-contract.md) 與 `schemas/history-package.schema.json`，嚴格定義欄位與引用。 |
| 查證流程 | [查證規則](history-verification.md)，區分原典記述、編輯整理、現代定位及待核換算。 |
| 楚漢首包 | `backend/static/data/history/chuhan-foundation.v1.json`，包含可回查的主張與缺漏範圍。 |
| 索引與驗證 | `backend/static/js/history-data.js`，在瀏覽器及 Node 使用相同邏輯。 |
| 比較頁 | `/history-lab`，提供時空探索、史論調查、人物編排；[玩法比較](history-play-comparison.md) 說明操作與初步判斷。 |
| 重建輸入 | `data/history-research/` 四份研究資料，供產生器重建；不是另一套遊戲資料格式。 |

選取範圍為秦亡、分封、楚漢合作與供給問題，核心目標為公元前 207 至 202 年；保守換算窗口延至前 208 年。22 件事件的現代年帶均保留待核狀態。鉅鹿、鴻門、入漢中、韓信受任、下邑、井陘、濰水、固陵、垓下等材料可以串接，但不代表完整戰爭年表。

全部現代座標與路線距離留為 null；四項經濟材料沒有補造數量。人物生卒尚未完整補查，life 明示 unknown。來源章節、角色記述和相對先後可用，精確日曆、交通計算、完整疆域與國力比較仍需另補。

## 實際連接方式

以鴻門會見為例，事件節點連到原紀年、鴻門等地名與人物當時角色。張良的早期職任保留韓王成脈絡；劉邦與漢高祖連到同一歷史身份，原庫的將帥類、帝王類文章仍各自呈現。角色主張再連到相應史記章節與定位段落。身份分類與事件職任可以不同。

下邑的韓信、英布、彭越標為「被提及」，不能據此安排成三人都在談話現場。同一批人物換到後續事件，讀取器取得不同角色與參與記述。這個變化由共用資料驅動。

在調查桌，玩家可以選史籍主張，也可以把原分析的某一段加入支持、質疑或脈絡。段落顯示原 ID、欄位與段號，並明示為原庫作者／AI 解讀。玩家自行留下解釋與未解疑問；頁面沒有固定心理答案或模型評分。

## 重建與核對

在專案根目錄執行，使用 Node，無需新增 npm 套件：

```powershell
node scripts/build-history-schema.cjs
node scripts/build-chuhan-package.cjs
node scripts/validate-history.cjs
node --test tests/history-data.test.cjs
node scripts/build-chuhan-package.cjs --check
```

`--check` 比對產生內容與已保存 JSON 是否逐位元組一致。原庫身份可另核對私人完整陣列：

```powershell
node scripts/build-chuhan-package.cjs --check --verify-library "完整人物快照的絕對路徑.json"
```

身份核對只讀 ID、姓名、分類，要求 962 筆原快照與 20 條精確對應；不讀取外部雲端，也不改寫快照。原庫沒有的十位人物保留為史料脈絡身份。

目前 21 項 Node 測試通過，包含錯誤證據連接、重複來源位置、紀年與引用、事件先後循環及大型倒序事件鏈。另以私人 jsdom 檢查 11 項實際 DOM 操作，包含 962 載入、段落加入、下載隔離、匯入競爭及失敗恢復。jsdom 檢查未確認真實瀏覽器畫面排版或實際檔案下載。

## 開啟比較頁

正常啟動既有後端後可開 `/history-lab`。預設載入內建人物庫；選「讀取本機人物 JSON」可讀完整人物陣列、characters 包裝，或原 App 的 customLegends／modifiedLegends 匯出格式。匯入在本頁記憶體處理。

本次私人預覽地址為 `http://127.0.0.1:8877/history-lab.html?local=1`，唯讀載入 2026 年 9 月 30 日保存的 962 筆快照。私人端點與預覽伺服器不在公開 App 內。localhost 僅限目前這台電腦，服務關閉後需重新啟動。

頁面只請求本地／本站資料，沒有 AI API、雲端寫入或瀏覽器持久儲存。比較下載保存玩家筆記、史料 ID 及原分析段落索引，排除原分析全文。關閉頁面前要下載才能保留筆記；目前尚未提供比較記錄的回讀功能。

## 下一個遊戲方向

依目前資料與互動結構，史論調查最直接使用原人物長文，可優先試作一次有收束的短調查。時空探索用於找到事件和人物；人物編排可延伸為場景創作。這是產品候選，尚未經玩家試玩驗證。

下一次驗證可以用下邑與固陵，對照張良、韓信或彭越的原分析與推薦、承諾、未會兵的記述，觀察玩家是否尋找反證、修正解釋並想追查下一題。先據這個結果選核心，再決定需要擴充哪批資料。
