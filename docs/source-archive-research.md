# 來源檔案館：研究與編輯核讀規則

版本：1.1.0
核讀日期：2026-10-02（Asia/Taipei）

## 交付的範圍

本次資料層把來源書目、文獻取得狀態、人物身份判別與具體命題核讀分開存放。

- `data/source-archive/catalog.json`：55 個來源登錄，其中 29 種古籍書目入口、26 個機構資料庫或人物資料入口。54 個入口成功讀取，CText 本次受存取限制，列為 unavailable。
- `data/source-archive/editorial-reviews.json`：38 組身份或混層問題核讀、65 組最小命題核讀，共涉及 128 張原人物卡。原庫 12 組完全同名雙卡均有身份核讀說明。
- 每組核讀只覆蓋列出的命題、原頁及定位。這 128 張卡的整篇分析、能力分數、價值評語、所有因果與數字仍未全部查證。
- 核讀由 Codex 輔助完成；`humanExpertReview:false` 明示未經人類史學專家複核。
- 其餘人物的來源線索、全文姓名命中、卷目定位及下載成果，應由檔案館產製清單另行統計；不能用本頁的來源入口數代替全文卷數或已核實人物數。

搜尋階段使用 Exa。第一輪設定 95 個候選結果名額；近現代增補 60 次搜尋請求共設定 172 個名額，其中 4 次請求遇限速後另行重查。這些名額含重複、不採用與失敗請求，**不是已核實史實數量**。另批次開啟書目、原典章節、機構說明與人物頁。最終留下 103 組具體核讀記錄，引用 88 個不同實讀頁面 URL。

## 四個層次分開顯示

| 層次 | 可以說什麼 | 不能推論什麼 |
| --- | --- | --- |
| 來源書目 | 這本書或資料庫有入口、涵蓋某時代、已讀條款或說明 | 已把全書全部卷下載；書內每件事都是真的 |
| 文獻取得 | 已取得某一修訂版及完整性指標，能離線檢索這份文字 | 每一字已對校影像；所有相關史料都已收齊 |
| 人物身份 | 這張卡的名字、帝號或同名角色已與指定文獻核對 | 已核實原卡全文、五維分數、心理分析及出生故事 |
| 命題核讀 | 文獻某段確有某項記述，且紀錄範圍明確 | 文獻記述必然等同客觀事實；一句引文證明整段宏觀因果 |

UI 建議用「有來源入口」「全文命中待核」「身份已核讀」「指定命題已核讀」。不得用一個綠色 verified 徽章同時表示四個層次。

## 共用來源登錄格式

每個來源含：

- `id`：穩定來源 ID，例如 `source:shiji`。
- `title/url/provider/type/coverage`：書名、原始入口、提供者、資源類型與涵蓋範圍。
- `access.mode/notes`：實際可存取層次及限制；入口框架可載入不等於本文可取得。
- `reuse.status/notes`：本包使用方式與尚未取得的重製權限。
- `retrievalStatus`：opened、search-only 或 unavailable；本版沒有把僅搜尋命中標為 opened。
- `accessedOn`：本次存取嘗試日期；unavailable 同樣保留嘗試日。
- `notes`：版本、語料依存、文學與史傳差異等編輯提示。

古籍索引類型 `primary-text-index` 指向承載原著的校錄平台。維基文庫是社群校錄提供者；頁面所載原著的作者、成書年代、今本版本與頁面修訂是不同欄位。

## 核讀記錄格式

身份組 `identityReviews` 必備：

- `id/recordIds/recordNames`：可回到原始卡片的精確 ID。即使人物標準名稱更正，原卡 ID 不改。
- `status`：identity-supported、correction-proposed、layer-separation 或 unresolved-identity。
- `issue/decision`：為何要核對、這次做到哪一步。
- `canonicalName/aliases`：有證據支持的檢索名；未能確定時 canonicalName 為 null。
- `evidence[]`：sourceId、實讀 url、卷篇或段落 locator、supportedFact、accessedOn、readingMethod、reviewScope。
- `notes`：未核部分；可另有 suggestedPolity、suggestedHistoricalRole、candidateNames、unsupportedOriginalClaims。

命題組 `readingReviews` 使用 `limited-claim-reviewed`，列出 claimsReviewed 與同樣可追溯的 evidence。此狀態只表示條目所列的小範圍命題。

`unsupportedOriginalClaims` 表示本輪證據不足，並不表示已證明原說法錯誤。其用途是阻止尚未支持的說法被提升為遊戲規則或歷史確值。

## 查證工作流程

1. **固定原始卡與原文。** 記錄原始 ID、姓名、角色、朝代與原文指紋。資料整理從覆蓋層開始，避免覆寫玩家珍視的原分析。
2. **辨認人物。** 先比姓名、異名、朝代、籍貫、官職與關係。姓名相同最多產生候選，不直接合併。
3. **找到原著、卷與段。** 用書目、全文命中及學術權威庫發現來源；進入原文再核對。搜尋結果摘要與現代百科可指路，不能取代原段。
4. **拆小命題。** 將「某年受某人任某職」「某史書如此評價」「分析者推測動機」拆開。不得拿任官記錄替人格推測背書。
5. **標明敘事層。** 正文、注文轉引、後世史評、神異、小說、今人評論各自保存。引文中的轉述仍記原作者與傳遞鏈。
6. **處理相依與矛盾。** 新舊唐書、南北史與各朝書可能共用材料；兩處相同敘述不自動變兩個獨立見證。版本或時間矛盾並存，附替代解釋。
7. **連人物、時間、地點、勢力。** 只有命題支持時才建立關聯。被提及不等於親臨；同一時代不等於同一政權；路線不等於精確里程。
8. **覆核並發布。** 以可回到原卷的定位做抽查；核讀不足保留 pending。人物身份核對、整篇原分析查證與史學專家審核分開統計。

## 引用與保存

對每份實際取得的文本保存：

- 原頁 URL、書名、篇卷、修訂版或抓取時點。
- 上游作者與提供者；原著版權與平台校錄授權分開。
- 原始回應／文字的 SHA-256、字數、取得時間與下載狀態。
- 正文整理方法與其限制：模板、章節導航、異體字、現代標點與注文不能默默刪改後冒稱原貌。
- 文本「完整」只能相對於已宣告的上游修訂／輸出格式；不代表今本沒有古代闕卷。
- 更新來源時保留舊版與差異，不覆蓋玩家已引用的段落。

本頁不指定下載成品的卷數，應以當次語料 manifest 的完成、失敗與完整性檢查為準。

## 授權與存取邊界

### 維基文庫與古代原著

古代原著多屬公有領域，但現代整理、標點、註釋、翻譯、圖像及平台貢獻需分開評估。保留原頁、修訂與平台授權資訊。清史稿涉及近代編修，catalog 使用 edition-dependent，不能把整個下載集合一律宣稱全球純公版。

### CBDB

已讀 [官方 API 說明](https://input.cbdb.fas.harvard.edu/cbdbapi/index.html)。2026 年 8 月 20 日起的說明按當前單機版日期及資料量區分條款：範圍內舊資料適用 CC BY-NC-SA 4.0；更晚或超範圍資料適用禁止商用、演繹與再散布／第三方存取的自訂條款。本次只提供入口與查證方法，沒有把線上庫鏡像進公開 App。

姓名 JSON 查詢只回第一個候選，單憑這個結果不能認定人名唯一。

### CText

本次開頁只取得安全檢查回應，未得到 FAQ 正文或古籍。回應要求使用獲授權的訂閱 API，本次沒有繞過限制。書目保留為人工或授權 API 的對校來源。

### 圖書館、博物館及近現代網站

故宮、國史館、國圖等入口可用於尋找版本、影像、文電與權威檔，但逐件開放閱覽不等於任意再分發。現代人物頁只保留連結與自行撰寫的最小摘要。機構立場被記錄，政治褒貶不轉為能力分數。

## 驗收清單

- catalog 來源 ID 不重複，所有 review 的 sourceId 都存在。
- recordIds 必須逐字匹配原庫；不從姓名拼接虛構 ID。
- 修正名稱、別名和政權只存在覆蓋層，原私有人物檔不變。
- 每個核讀結論有實讀 URL、定位與限定範圍。
- 不將書目完整率、全文命中率、身份核讀率及逐命題查證率相加或互換。
- 異名可能同人，同名也可能異人；未決的南宮條目保持 unresolved。
- 所有現代網站完整文章、機構資料庫及受限圖像均未由本研究檔任意鏡像。

## 近現代人物增補結果

原庫標示為「中華民國」「中華人民共和國」「民國/現代」共 **72 張人物卡**；扣除同名雙卡及蔣介石／蔣中正、李宗仁／李宗仁(名臣)的同人別名後，對應 **65 位歷史人物**。

本輪新增 **58 組**核讀：3 組姓名對接、55 組身分或任職最小命題。連同第一輪覆蓋的 14 張卡，72 張均有至少一項可回到實讀機構頁面的核讀記錄。

這是「每張卡有基本來源核讀」的完整覆蓋，**尚不是每人的所有史料、完整傳記或原卡長篇分析全部查證**。沒有把名字搜尋網址當作證據，沒有把百科參考文獻列表冒充已讀原書。

### 來源與核讀深度

- 國立公共資訊圖書館：新增20位人物條目；張作霖、吳佩孚、曹錕、黃興這4位本輪只核人物資料表，保留為 institutional-person-metadata。
- 總統府、行政院、國防部：歷任總統、院長與部長的具名任職資料。
- 國史館：實读《汪兆銘史料》全宗概述的小傳，印刷頁447。這並不代表59卷文件及30卷照片均已下載。
- 國父紀念館：1915年12月25日年譜條，核蔡鍔的護國軍職位，保留註161以便再追原書。
- 檔案管理局：張學良於西北剿匪總司令部的職位；附檔尚未逐件調閱。
- 湖南省檔案局、全國政協、官方軍事網站及地方政府人物資料：過去身分、職位或具名事件。
- 十位元帥共用一份具名授銜記錄；江青、張春橋、陳伯達共用第九屆中央委員名單。這13条各自核對姓名，但共用文件不是13份獨立交叉證據。
- 薄熙來只採法院文書身分段的過去職務，沒有保存住址等無關個資，也沒有從司法或政治用語推導人格分數。

### 再利用界線

這一批機構網站只保存來源 metadata、頁內定位與自己撰寫的短摘要，不複製現代傳記全文、照片或整個資料庫。公開可讀與可批次重製是兩件事；網站條款未知或要求授權時，不當作開放授權語料。

來源文件反映其撰寫與編纂立場。要把政策成效、戰役責任、性格或因果轉成遊戲規則，還需同時期文書、不同觀點材料與專門研究交叉檢查；目前這些條目均不標為人類史學專家審定。
